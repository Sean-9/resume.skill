# 版面规范（typography.md）

**Phase 6 渲染的唯一样式来源。** 改 `scripts/render.py`（docx）或 `scripts/render_pdf.py`（pymupdf pdf）之前必须读本文件，两端实现同一套数值，保证 docx / LibreOffice pdf / pymupdf pdf 观感一致，不会每次生成都不一样。

> 规则只有一套：中英同源字体、三级字号、三档间距、日期右对齐、拉丁词不断行。任何一处实现与本文不符，按本文为准重写。

---

## 1. 字体

- **中文与英文必须是同一字源**：Noto Sans CJK SC。否则中文走回退字体、英文走另一套，字重与字面大小对不齐，版面发散。
- docx：`w:ascii` 与 `w:eastAsia` **同时**设为同一字体名（`Noto Sans CJK SC`）。
- pdf：全文使用同一个 `fontfile`，不切换字体。
- 字体文件放 `assets/`，名可为 `.otf` 或 `.ttc`，脚本自动探测。

## 2. 三级字号对比（必须拉开差距，>=4pt 的档差）

| 层级 | 场景 | 字号 | 对齐/颜色 |
|---|---|---|---|
| H1 姓名 | 页首 | 20 | 居中，加粗 |
| 定位语 | 姓名下方 | 10.5 | 居中，深灰 |
| 联系方式 | 定位下方 | 9 | 居中，灰 |
| **H2 章节标题** | 教育背景 / 论文与专利 / … | **14** | 左对齐，加粗，下缘细线 |
| **H3 条目标题** | 公司 / 学校 / 项目 / 论文名 | **11.5** | 左对齐，加粗，日期右对齐 |
| 正文 | bullet | 10 | 左对齐 |
| 附注 note | 英文全称 / 次要说明 | 9 | 灰色缩进 |

**判据**：H2 比正文大 ≥4pt（14 vs 10），H3 比正文大 ≥1.5pt（11.5 vs 10）。肉眼能直接分出三层，不靠颜色或下划线硬撑。

## 3. 三档间距（必须拉开差距，相等 = 没有分组感）

| 档位 | 场景 | 值（pt） |
|---|---|---|
| 章节间距 | 章节标题**上方** | **6.5** |
| 条目间距 | 相邻条目（公司/项目块）**之间** | **2.5** |
| bullet 间距 | 同一条目内 bullet **之间** | **1.0** |

补充：条目标题与首条 bullet 之间 2.0；附注与下一条 bullet 之间 1.5。

**判据**：同一章内 bullet 挤在一起（1.0），条目之间明显分开（2.5），章节之间更明显（6.5）。三档从密到疏，视觉上"哪几行是一组"一眼可辨。

## 4. 日期右对齐

- 条目标题行：标题 + 角色靠左，**日期用右对齐制表位钉到右边界**，不要跟在标题后面漂。
- docx：在段落加右对齐制表位，位置 = 页面内容区右边界（A4，左右边距 2.2cm → 制表位在 16.5cm）；文本 = `{标题} {角色}\t{日期}`。
- pdf：标题在左边界画，日期先量宽度，从右边界向左画，同一基线；标题可用宽度 = 总宽 - 日期宽度 - 6pt，超长时标题换行但日期始终钉在右边界。

## 5. 中英断词

- **拉丁单词不得从中间断开**（`The Visual Compute/r`、`Distil/lation` 都是错误样例）。
- docx：交给 Word 原生换行，不要在源码里手动断词。
- pdf（render_pdf.py 手动换行）：把文本拆成"原子"——中文单字一个原子、拉丁/数字词一个原子、空白单独处理；**换行只发生在原子边界**。中文可逐字断，拉丁只在词间断。
- 判据：提取 PDF 文本后，任意拉丁单词在行尾处不得出现被劈成两半的情形。

## 6. 论文标题降级

- **条目标题用短中文名**（尽量 ≤20 字），如「跨模态蒸馏的最佳视点选择」。
- **英文全称放 `note` 字段**，渲染成 9pt 灰色附注行，不要当主标题。
- 判据：条目标题行不超过一行；80 字符英文标题不得占据版面两行。

## 7. 超页删减优先级

目标默认 1 页，最多 2 页。内容放不下时按下列顺序删，**删之前必须问用户**（见 SKILL.md「运行铁律」）：

1. 学生工作 / 荣誉里的次要 bullet
2. 项目经历中非核心的条目（保留论文与最新实习）
3. 技能 / 证书合并成一行
4. 压缩日期格式与描述性形容词（不删数字、不改数字）
5. 最后才考虑删论文 / 核心实习 / 教育信息

**任何删减都不改变数字与事实，只改变取舍与措辞。**
